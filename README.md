# LMS — Neo Gyaan Learning Management System.

Neo Gyaan is a modern, high-performance Learning Management System (LMS) built with React 19, TypeScript, Vite, Tailwind CSS v4, and Framer Motion. It features an ultra-responsive Bento Grid UI, interactive sandbox widgets, verifiable digital credentials, dynamic student testimonials, transparent tuition tiers, and a simulated Dummy Payment Gateway (supporting UPI, Cards, and Net Banking)

## ✨ Features
- **Bento Grid Architecture**: Asymmetric cards, glassmorphic accents, and micro-interactions.
- **Interactive Hero & Code Sandbox**: Live React/TypeScript code toggle with reactive simulation.
- **Scroll-Triggered Animations**: Smooth reveal effects powered by Framer Motion.
- **Dummy Payment Gateway**: Simulated checkout supporting UPI / QR code, Credit/Debit cards, and Net Banking with instant course unlocking and invoice generation.
- **Testimonials Showcase**: Alumni reviews from engineers and designers at Google, Swiggy, Zerodha, CRED, Razorpay.
- **Verified Credentials**: Accredited digital certificates with verifiable hashes.
- **Mobile Responsive**: Adaptive design optimized for all screen dimensions from 360px up to 4K displays.

## 🛠️ Tech Stack
- **Frontend**: React 19, Vite, Tailwind CSS v4, Framer Motion, Wouter, TanStack Query, Lucide Icons
- **Backend**: Node.js, Express 5, Pino Logger
- **Package Manager**: pnpm workspaces

## 🚀 Getting Started.

```bash
# Install dependencies
pnpm install

# Run frontend development server (port 5173)
pnpm dev

# Run API server (port 5000)
pnpm dev:api

# Build for production
pnpm build
```
